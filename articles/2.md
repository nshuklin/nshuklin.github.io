# Тема 2. JavaScript

Курс: «Кроссплатформенная разработка».

## Аннотация

Тема посвящена основам языка JavaScript: истории появления, стандарту ECMAScript, основным свойствам языка, типам данных, преобразованиям типов, переменным, управляющим конструкциям, функциям, замыканиям, прототипам и классам. Материал соответствует итоговой презентации темы 2 и формирует базу, необходимую для дальнейшего изучения клиентской и кроссплатформенной разработки.

## Цель темы

Сформировать у студента целостное представление об основах JavaScript и его ключевых механизмах:

- что такое JavaScript и как он связан со стандартом ECMAScript;
- какие свойства языка делают его гибким и широко применимым;
- какие типы данных существуют и как они преобразуются;
- как объявлять переменные и почему `var` считается устаревшим;
- как работают ветвления, циклы, функции и стрелочные функции;
- что такое замыкания и как они позволяют сохранять состояние;
- как устроено прототипное наследование и как с ним связаны классы из ES2015.

После изучения темы студент должен уметь читать и писать простой код на JavaScript, понимать разницу между примитивами и объектами, осознанно использовать `let` и `const`, применять функции и замыкания, а также понимать базовую механику прототипного наследования и классов.

## 1. Что такое JavaScript?

JavaScript — это язык программирования, который изначально создавался для придания интерактивности веб-страницам, но со временем стал полноценным языком общего назначения. Сегодня он используется в браузерах, серверных средах, мобильной и кроссплатформенной разработке.

Важно различать сам язык и его стандарт:

- **ECMAScript** — стандарт языка JavaScript.
- ECMAScript описывает синтаксис и базовую семантику языка, но не описывает API конкретной среды исполнения.
- Первая версия языка была разработана в 1995 году компанией Netscape.
- Автор языка — Брендан Эйх.
- В 1997 году вышла первая редакция стандарта ECMAScript.

Таким образом, когда говорят о возможностях языка, часто имеют в виду версию стандарта ECMAScript, которую поддерживает среда выполнения: браузер, Node.js, Deno, Bun и другие окружения.

## 2. Основные свойства языка

JavaScript обладает рядом свойств, которые определяют его характер.

### 2.1. Мультипарадигменность

На JavaScript можно писать в разных стилях:

- императивном;
- объектно-ориентированном;
- функциональном;
- событийно-ориентированном.

Один и тот же язык позволяет решать задачи разными подходами.

### 2.2. Интерпретируемость

Код выполняется средой исполнения. Современные движки активно используют JIT-компиляцию и оптимизации, но концептуально язык остаётся интерпретируемым: программа выполняется в уже готовой среде, а не компилируется заранее в отдельный исполняемый файл традиционным способом.

### 2.3. Нестрогая типизация

Переменные не имеют жёстко закреплённого типа, а значения могут автоматически преобразовываться в операциях. Это делает язык гибким, но требует внимательности: многие ошибки возникают именно из-за неявных преобразований.

### 2.4. Автоматическое управление памятью

Программист не выделяет и не освобождает память вручную. Этим занимается среда исполнения с помощью сборщика мусора.

### 2.5. Прототипное наследование

Объекты могут наследовать свойства и методы от других объектов через цепочку прототипов. Это альтернатива классическому наследованию, знакомому по таким языкам, как Java или C++.

---

## 3. Актуальные движки JavaScript

JavaScript выполняется не «сам по себе», а в среде исполнения, которая использует движок языка. Среди актуальных серверных реализаций можно выделить:

| Среда | Движок |
|---|---|
| Node.js | V8 |
| Deno | V8 + Rust |
| Bun | JavaScriptCore |

Движок отвечает за разбор, выполнение и оптимизацию кода. Поэтому поведение языка может незначительно отличаться в разных средах, особенно в части доступных API и производительности.

## 4. Рейтинг TIOBE

Рейтинг TIOBE — один из известных индексов популярности языков программирования. Он оценивает популярность на основе количества поисковых запросов, содержащих название языка.

JavaScript в таких рейтингах традиционно занимает высокие позиции, так как используется:

- во фронтенде;
- в серверной разработке;
- в кроссплатформенных приложениях;
- в инструментах сборки и автоматизации;
- в экосистеме мобильных и настольных решений.

Для студента важно понимать: популярность JavaScript обусловлена не только историческим положением в браузерах, но и огромной экосистемой инструментов и сред исполнения.

## 5. Нестрогая типизация с типами

Несмотря на нестрогую типизацию, типы данных в JavaScript существуют. Их можно разделить на две большие группы:

### 5.1. Примитивные типы данных

- `boolean`
- `string`
- `number`
- `bigint`
- `null`
- `undefined`
- `symbol`

### 5.2. Ссылочные типы данных

- объекты;
- массивы;
- функции;
- регулярные выражения;
- ошибки;
- даты и другие встроенные объектные типы.

Принципиальная разница:

- примитивы хранят простое значение;
- объекты хранят ссылку на данные, а не сами данные напрямую.

Это различие критично при сравнении значений, копировании данных и передаче их в функции.

## 6. Примитивные типы данных

### 6.1. `boolean` и `string`

Тип `boolean` имеет всего два значения:

```js
true
false
```

Он используется в условиях, флагах и логических выражениях.

Тип `string` представляет текстовые данные. Примеры литералов:

```js
"Привет мир!"
'Привет мир!'
`Привет${world}!`
```

Особенности строк:

- можно использовать двойные, одинарные и шаблонные кавычки;
- шаблонные строки поддерживают интерполяцию через `${}`;
- строки неизменяемые: нельзя изменить символ внутри существующей строки без создания новой строки.

Пример:

```js
const s = 'Привет';
s[0] = 'п';
console.log(s); // 'Привет'
```

Попытка изменить символ не приведёт к ожидаемому результату, потому что строка остаётся прежней.

---

### 6.2. `number`

Тип `number` представляет числа с плавающей запятой двойной точности. Примеры литералов:

```js
42
3.14
Infinity
-Infinity
NaN
```

Особые значения:

- `Infinity` — положительная бесконечность;
- `-Infinity` — отрицательная бесконечность;
- `NaN` — результат некорректной числовой операции.

Пример:

```js
console.log(1 / 0);        // Infinity
console.log('текст' * 2);  // NaN
```

Важно помнить, что `NaN` не равен самому себе при строгом сравнении:

```js
console.log(NaN === NaN); // false
```

Для проверки значения на `NaN` существуют отдельные средства, например `Number.isNaN()` или `isNaN()`, но они ведут себя по-разному.

---

### 6.3. `bigint`

`bigint` появился в стандарте ES2020 и представляет целые числа произвольной длины. Он нужен там, где обычных чисел типа `number` уже недостаточно.

Примеры:

```js
const big = 9007199254740991n;
const also = BigInt("12345678901234567890");
```

Особенности:

- литерал `bigint` заканчивается суффиксом `n`;
- можно создать через функцию `BigInt()`;
- `bigint` нельзя свободно смешивать с `number` в большинстве операций без явного преобразования.

---

### 6.4. `null` и `undefined`

`null` и `undefined` — два особых типа данных.

- `null` — переменная существует, но значение намеренно отсутствует.
- `undefined` — значение не было присвоено, либо переменной фактически нет.

Пример:

```js
let a = null;
let b;

console.log(a); // null
console.log(b); // undefined
```

Важная особенность:

```js
console.log(null == undefined);  // true
console.log(null === undefined); // false
```

При нестрогом сравнении они равны, но их типы различаются. Также они не равны `false`:

```js
console.log(null == false);      // false
console.log(undefined == false); // false
```

Отдельно стоит запомнить историческую особенность:

```js
console.log(typeof null); // "object"
```

Это не современное поведение по смыслу, а наследие старой спецификации, то есть известный исторический баг, оставленный ради совместимости.

---

### 6.5. `symbol`

`symbol` появился в ES2015 и представляет уникальный и неизменяемый идентификатор.

Пример:

```js
const id = Symbol("id");
const id2 = Symbol("id");

console.log(id === id2); // false — каждый символ уникален
```

Даже если описание символов совпадает, сами символы всё равно различаются.

Символы часто используются для создания уникальных ключей объектов и служебных идентификаторов.

---

## 7. Служебный оператор `typeof`

Оператор `typeof` позволяет определить тип значения.

Примеры:

```js
typeof 42         // "number"
typeof "str"      // "string"
typeof true       // "boolean"
typeof undefined  // "undefined"
typeof null       // "object"  ← историческая особенность
typeof Symbol()   // "symbol"
typeof 10n        // "bigint"
```

Важно помнить:

- `typeof` возвращает строку;
- для `null` он возвращает `"object"` из-за исторической ошибки;
- для функций `typeof` вернёт `"function"`, хотя функции являются объектами.

## 8. Обёртки над примитивами

Вокруг некоторых примитивов существуют объекты-обёртки: `Boolean`, `String`, `Number` и другие. Они дают доступ к методам, но в современном коде создавать такие объекты через `new` обычно не нужно.

Плохой пример:

```js
const x = new Boolean(false);

if (x) {
  // Я здесь!
} else {
  // Но не здесь
}
```

Почему так происходит? Потому что `new Boolean(false)` создаёт **объект**, а любой объект в логическом контексте приводится к `true`.

Хороший пример:

```js
const x = Boolean(false);

if (!x) {
  // Я здесь!
} else {
  // Но не здесь
}
```

Здесь `Boolean(false)` возвращает примитивное значение `false`, как и ожидается.

Вывод: для преобразования к булеву типу следует использовать вызов `Boolean(...)`, а не создание объекта через `new Boolean(...)`.

## 9. Объектов бесконечно много

К ссылочным типам относятся встроенные объекты. Среди основных:

- `Object`
- `Array`
- `Function`
- `RegExp`
- `Error`
- `Date`
- и многие другие.

Важно понимать, что в JavaScript объекты используются повсюду:

- массивы — это объекты;
- функции — это объекты;
- ошибки, даты, регулярные выражения — тоже объекты.

## 10. Литералы для встроенных объектов

Во многих случаях объекты можно создавать не только через конструкторы, но и с помощью литералов. Литеральная форма обычно короче и предпочтительнее.

Примеры через конструкторы:

```js
new Object()
new Array(1, 2, 3)
new Function('a, b', 'return a + b')
new RegExp('\\w', 'g')
```

Более естественные литеральные формы:

```js
{}
[1, 2, 3]
function(a, b) { return a + b; }
/\w/g
```

В современном коде литералы используются чаще, так как они читаются проще и реже приводят к неожиданным эффектам.

## 11. Преобразование типов

JavaScript активно выполняет преобразования типов. Их важно понимать, потому что значительная часть «странных» ошибок связана именно с неявными преобразованиями.

Существуют три основных преобразования:

1. `ToBoolean` — к логическому типу.
2. `ToString` — к строке.
3. `ToNumber` — к числу.

---

### 11.1. Преобразование `ToBoolean`

Все объекты приводятся к `true`, включая пустые массивы и пустые объекты.

Примитивы тоже обычно приводятся к `true`, кроме следующих значений:

```js
false
null
undefined
''
0
-0
NaN
```

Это список **falsy**-значений.

Примеры:

```js
Boolean({});     // true
Boolean([]);     // true
Boolean('');     // false
Boolean(0);      // false
Boolean('0');    // true, потому что непустая строка
```

---

### 11.2. Преобразование `ToString`

При преобразовании к строке:

- примитивы получают строковое представление;
- объекты вызывают метод `toString()`.

Примеры:

```js
String(42);        // "42"
String(true);      // "true"
String(null);      // "null"
String([1, 2, 3]); // "1,2,3"
```

---

### 11.3. Преобразование `ToNumber`

При преобразовании к числу:

- `true` превращается в `1`;
- `false` превращается в `0`;
- объекты проходят через числовое преобразование;
- строки разбираются по определённым правилам.

Правила для строк:

1. пустая строка — `0`;
2. выполняются удаление пробелов и обработка знака;
3. читаются цифры;
4. если встречается недопустимый символ, результат — `NaN`.

Примеры:

```js
Number('');       // 0
Number('  42 ');  // 42
Number('-42');    // -42
Number('42px');   // NaN
Number(true);     // 1
Number(false);    // 0
```

---

## 12. Явное и неявное преобразование

Преобразования типов могут быть:

- **явными** — когда программист сам вызывает преобразование;
- **неявными** — когда преобразование происходит автоматически в контексте операции.

Примеры явных преобразований:

```js
Boolean(0);       // false
String(42);       // "42"
Number('42');     // 42
`${42}`;          // "42"
```

Всё остальное, что происходит автоматически в условиях, арифметике, сравнениях и логических операторах, относится к неявным преобразованиям.

---

## 13. Неявное преобразование в `Boolean`

Неявное логическое преобразование происходит в следующих конструкциях:

- `if`
- `for`
- `while`
- `do-while`
- тернарный оператор `?:`
- операторы `&&` и `||`

Также часто используется двойное отрицание:

```js
!!value
```

Оно преобразует значение к булеву типу.

Примеры:

```js
if (value) {
  // выполнится, если value приводится к true
}

const x = value ? 1 : 0;
```

Операторы `&&` и `||` сначала вычисляют и преобразуют левую часть, после чего могут остановиться или перейти к правой.

Примеры:

```js
!isComputed && doComputation();

const x = y && z;
const x = y || z;
```

Важно понимать:

- `&&` возвращает левое значение, если оно ложно, иначе правое;
- `||` возвращает левое значение, если оно истинно, иначе правое.

---

## 14. Неявное преобразование в `Number`

Числовые преобразования происходят в математических и битовых операциях. Особняком стоит бинарный оператор `+`, потому что при участии строк он может выполнять конкатенацию.

Примеры числовых операций:

```js
'5' - 1;   // 4
'5' * 2;   // 10
'10' / 2;  // 5
true + 1;  // 2
false + 1; // 1
```

Но если используется `+` и один из операндов — строка, то второй тоже преобразуется к строке:

```js
'5' + 1;       // "51"
1 + '5';       // "15"
'цена: ' + 42; // "цена: 42"
```

Если в числовом контексте участвует объект, движок пытается получить примитивное значение, обычно через `valueOf()`, а не сразу через `toString()`.

## 15. Операторы сравнения

В JavaScript есть несколько видов сравнения, и их важно различать.

### 15.1. Строгое сравнение

```js
===
!==
```

Оно не выполняет преобразование типов. Значения сравниваются как есть.

Примеры:

```js
1 === 1;             // true
1 === '1';           // false
null === undefined;  // false
```

### 15.2. Сравнение по ссылке

Все объекты сравниваются по ссылке, и это справедливо как для `==`, так и для `===`.

```js
{} === {} // false
```

Даже два одинаковых объекта не равны, потому что это разные ссылки.

### 15.3. Нестрогое сравнение

Операторы:

```js
==
!=
>
<
>=
<=
```

Часто они предпочитают числовое преобразование.

Важные случаи:

```js
null == undefined;   // true
NaN != NaN;          // true
isNaN(NaN);          // true
isNaN('string');     // true
Object.is(NaN, NaN); // true
```

На практике для проверки равенства почти всегда лучше использовать `===` и `!==`, так как они предсказуемы и не выполняют скрытых преобразований.

## 16. Переменные

В JavaScript есть три способа объявить переменную:

```js
var
let
const
```

### 16.1. `var`

Старый способ объявить изменяемую переменную.

```js
var x = 10;
```

### 16.2. `let`

Рекомендуемый способ объявить изменяемую переменную. Ограничен областью видимости блока `{}`.

```js
let y = 20;
y = 30;
```

### 16.3. `const`

Способ объявить константу, то есть переменную, которую нельзя переприсвоить.

```js
const z = 30;
```

Важно: `const` запрещает переприсваивание, но не делает содержимое объекта неизменяемым.

```js
const task = { done: false };
task.done = true; // допустимо
```

## 17. Почему `var` устарел?

У `var` есть две серьёзные проблемы:

1. **Функциональная область видимости**, а не блочная.
2. **Всплытие** (hoisting).

Пример всплытия:

```js
console.log(a); // undefined
var a = 42;
```

Фактически движок «поднимает» объявление переменной до выполнения кода, но не поднимает присвоенное значение. Поэтому до строки присваивания переменная существует, но равна `undefined`.

С `let` поведение другое:

```js
console.log(a); // ReferenceError
let a = 42;
```

До момента объявления переменная находится во временной мёртвой зоне.

Именно поэтому в современном коде `var` обычно не используют.

## 18. Порядок выбора способа объявления переменной

Рекомендуемый порядок:

1. `const` — по умолчанию.
2. `let` — если значение нужно переприсваивать.
3. `var` — признак легаси-кода.

Такой подход делает код более предсказуемым и снижает количество ошибок.

## 19. Ветвление

Для ветвления в JavaScript используются `if` и `switch`.

### 19.1. `if`

```js
if (statement) {
  // код
} else if (statement) {
  // код
} else {
  // код
}
```

### 19.2. `switch`

```js
switch (x) {
  case statement:
    // код
    break;
  default:
    // код
}
```

`switch` удобен, когда нужно сравнить одно значение с несколькими вариантами.

## 20. Циклы

### 20.1. Классический `for`

```js
for (initialization; statement; every step) {
  // тело цикла
}
```

Пример:

```js
for (let i = 0; i < 3; i++) {
  console.log(i);
}
```

### 20.2. `for...in`

Используется для перебора ключей объекта:

```js
for (const index in someObject) {
  console.log(index);
}
```

### 20.3. `for...of`

Используется для перебора значений итерируемых объектов, например массивов:

```js
for (const value of someArray) {
  console.log(value);
}
```

### 20.4. `while`

Выполняется, пока условие истинно:

```js
while (statement) {
  // код
}
```

### 20.5. `do-while`

Сначала выполняет тело, затем проверяет условие:

```js
do {
  // код
} while (statement);
```

Особенность `do-while`: тело выполнится минимум один раз, даже если условие сразу окажется ложным.

## 21. Функции

В JavaScript функции можно создавать несколькими способами.

### 21.1. Через конструктор `Function`

```js
new Function(...args, functionBody)
```

Пример:

```js
const sum = new Function('a', 'b', 'return a + b');
```

### 21.2. Функциональное объявление

```js
function name(params) {
  // тело функции
}
```

Пример:

```js
function sum(a, b) {
  return a + b;
}
```

### 21.3. Функциональное выражение

```js
const name = function(params) {
  // тело функции
};
```

Пример:

```js
const sum = function(a, b) {
  return a + b;
};
```

### 21.4. Именованное функциональное выражение

```js
const name = function otherName(params) {
  // тело функции
};
```

Имя внутри выражения может быть полезно для рекурсии или отладки.

## 22. Стрелочные функции

Стрелочные функции появились в ES2015 и имеют более компактный синтаксис.

Пример:

```js
const functionName = (...args) => {
  args.forEach(e => console.log(e));
};
```

Их особенности:

1. Определяются только через функциональные выражения.
2. Не имеют собственного `this`.
3. Не имеют собственного объекта `arguments`.

Благодаря лексическому `this` стрелочные функции особенно удобны в колбэках и внутри методов объектов.

## 23. Замыкание

**Замыкание** — это функция вместе с лексическим окружением, в котором она была создана.

Иными словами, функция запоминает переменные, которые были доступны в момент её создания, и может обращаться к ним даже тогда, когда внешняя функция уже завершилась.

Ключевые свойства замыканий:

- внешняя функция завершилась, но переменные всё равно живут;
- можно создать приватное состояние без классов;
- замыкания используются для счётчиков, фабрик, отложенных вызовов и других паттернов;
- замыкание даёт доступ к самой переменной, а не к снимку её значения.

---

### 23.1. Классический пример замыкания

Пример счётчика:

```js
function counter() {
  let a = 0;

  return {
    increment() {
      a++;
    },
    decrement() {
      a--;
    },
    getValue: () => a,
  };
}

const counter1 = counter();
const counter2 = counter();

counter1.increment();
counter1.increment();

console.log(counter1.getValue()); // 2
console.log(counter2.getValue()); // 0
```

Что здесь происходит?

- Каждый вызов `counter()` создаёт новое лексическое окружение.
- Переменная `a` не доступна снаружи напрямую.
- Методы `increment`, `decrement` и `getValue` сохраняют доступ к этой переменной через замыкание.
- `counter1` и `counter2` имеют независимые состояния.

Это и есть практическая сила замыканий: состояние можно хранить без глобальных переменных и без классов.

---

### 23.2. Фабрика функций

Замыкания также позволяют создавать функции с заранее зафиксированными параметрами.

Пример:

```js
function creator(factor) {
  return function(num) {
    return num * factor;
  };
}

const doubler = creator(2);
console.log(doubler(3)); // 6

const tripler = creator(3);
console.log(tripler(3)); // 9
```

Функция `creator` возвращает новую функцию, которая помнит значение `factor`. Это называется фабрикой функций.

## 24. Прототипы: функции-классы

Все объекты в JavaScript имеют скрытую ссылку на прототип. В учебных примерах её часто показывают через свойство `__proto__`.

Функции имеют свойство `prototype`, которое передаётся в прототип создаваемым экземплярам.

Если свойства нет в текущем объекте, оно ищется по цепочке прототипов «родителей».

Пример цепочки:

```text
object → prototype → prototype.prototype → ... → null
```

Именно так работает прототипное наследование: объект не обязательно содержит все свойства сам — часть он может брать из прототипа.

---

## 25. Функции-конструкторы

До появления классов в ES2015 для создания однотипных объектов часто использовали функции-конструкторы.

Пример:

```js
function PersonClass(name, age) {
  this.name = name;
  this.age = age;
  this.toString = () => `Name: ${name}, age: ${age}`;
}

const person = new PersonClass('Иван', 23);

console.log(person.toString()); // Name: Иван, age: 23
```

Что делает оператор `new`:

1. создаёт новый объект;
2. привязывает к нему `this`;
3. выполняет функцию-конструктор;
4. возвращает созданный объект.

---

## 26. Прототипное наследование

Прототипное наследование позволяет одному объекту использовать свойства и методы другого.

Пример:

```js
function Animal(sound) {
  this.sound = sound;
  this.says = () => `Animal says ${this.sound}`;
}

function Cat() {
  Animal.call(this, 'Мяу');
}

Cat.prototype = Object.create(Animal.prototype);
Cat.prototype.constructor = Cat;
```

Разбор:

- `Animal.call(this, 'Мяу')` вызывает конструктор `Animal` в контексте создаваемого `Cat`, чтобы унаследовать свойства.
- `Object.create(Animal.prototype)` создаёт новый объект, прототипом которого является `Animal.prototype`.
- `Cat.prototype.constructor = Cat` восстанавливает ссылку на конструктор.

Так выстраивается цепочка прототипов.

---

## 27. ES2015: появление классов

В стандарте ES2015 появились классы. Они не отменяют прототипное наследование, а дают более удобный синтаксис.

Пример:

```js
class Animal {
  constructor(sound) {
    this.sound = sound;
  }

  says = () => `Animal says ${this.sound}`;
}

class Cat extends Animal {
  constructor() {
    super('Мяу');
  }
}
```

Что здесь важно:

- `constructor` — метод инициализации объекта;
- `extends` — указывает, от какого класса наследуется текущий;
- `super(...)` — вызывает конструктор родительского класса.

Классы делают объектно-ориентированный код визуально более привычным, но внутри всё равно используются прототипы.
