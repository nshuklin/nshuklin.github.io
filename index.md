# Курс «Веб-разработка»: кроссплатформенные приложения на JavaScript

Учебно-методические материалы курса Новосибирского государственного университета.
Курс посвящён кроссплатформенной разработке на стеке **JavaScript / TypeScript → Vue 3 → PWA → Capacitor**: от базового языка до публикации мобильного приложения в сторе.

## Источники

При подготовке материалов используются:

- официальная документация технологий (Vue, Vite, Pinia, Vue Router, Capacitor, TypeScript и др.);
- [MDN Web Docs](https://developer.mozilla.org/ru/) от Mozilla;
- [Web-standards.ru](https://web-standards.ru/) — сайт сообщества «Веб-стандарты»;
- [Metanit.com](https://metanit.com/) — русскоязычные руководства по JavaScript, TypeScript, Vue и смежным технологиям.

Каждая статья завершается списком литературы с прямыми ссылками по указанным источникам.
