# Курс «Веб-разработка»: кроссплатформенные приложения на JavaScript

Учебно-методические материалы курса Новосибирского государственного университета.
Курс посвящён кроссплатформенной разработке на стеке **JavaScript / TypeScript → Vue 3 → PWA → Capacitor**: от базового языка до публикации мобильного приложения в сторе.

- **Объём:** 20 тем × 4 академических часа (2 ч теории + 2 ч практики) = 80 акад. часов.
- **Аудитория:** студенты, уже знакомые с основами программирования и базовым JavaScript.
- **Стиль изложения:** формально-деловой с нотками юмора там, где это уместно (определения остаются строгими — шутят примеры и аналогии).

## Структура материалов

Каждой теме соответствует отдельная папка `Тема NN. <Название>/`:

```
Тема NN. <Название>/
├── Статья.md        — подробная статья: теория, практика, контрольные вопросы,
│                      домашнее задание, типичные ошибки, список литературы
├── Презентация.md   — краткая нарезка для слайдов (10–14 слайдов с тезисами
│                      и заметками докладчика)
└── Картинки/        — тематические SVG-иллюстрации (схемы и дружественные
                       юмористические рисунки) для вставки в презентацию
```

Методический план курса целиком: [`Методический план курса.md`](./Методический%20план%20курса.md).

## Сквозной проект курса

Все практические работы опираются на единый сквозной проект — **трекер задач «TaskFlow»**:

- **Стек:** Vue 3 (Composition API, `<script setup>`) + TypeScript (strict) + Vite; с темы 18 — Capacitor для упаковки в Android/iOS.
- **Домен:** пользователи и команды, проекты, задачи, канбан-доска со статусами, теги, дедлайны, комментарии, вложения, уведомления.
- **Динамика:** темы 1–8 закладывают фундамент (язык, окружение, инфраструктура, архитектура, UI), темы 9–17 наращивают функциональность (компоненты, маршрутизация, сеть, realtime, офлайн, тесты, безопасность), темы 18–20 упаковывают проект в мобильное приложение и доводят до релиза.
