# Тема 08. Основы Vue 3: реактивность, компоненты, props/emits, жизненный цикл

## Практическая часть

Контекст: мы закладываем фундамент учебного проекта — трекера задач с проектами, канбан-доской и тегами. Сегодня строим прототип списка задач: тот самый «Todo-лист», который к теме 12 обрастёт маршрутизацией, состоянием и сетью.

### Задание 1. Скаффолд проекта и модель данных (~30 минут)

1. Создайте проект на Vite с шаблоном Vue + TypeScript:

```bash
npm create vite@latest my-app -- --template vue-ts
cd my-app
npm install
npm run dev
```

2. Откройте `http://localhost:5173`, убедитесь, что видите стартовую страницу Vite + Vue.

3. Создайте файл `src/types/task.ts`:

```ts
export type TaskStatus = 'todo' | 'in-progress' | 'done'

export interface Task {
  id: number
  title: string
  description: string
  status: TaskStatus
  deadline?: string
  tags: string[]
}
```

4. Замените содержимое `App.vue` заглушкой:

```vue
<script setup lang="ts">
import type { Task } from './types/task'
import { ref } from 'vue'

const tasks = ref<Task[]>([
  { id: 1, title: 'Разобраться с реактивностью', description: '', status: 'done', tags: ['учёба'] },
  { id: 2, title: 'Собрать проект', description: 'Список задач — первый шаг', status: 'in-progress', tags: ['проект'] },
  { id: 3, title: 'Настроить ESLint', description: '', status: 'todo', tags: ['инструменты'] },
])
</script>

<template>
  <main>
    <h1>My App</h1>
  </main>
</template>
```

**Ожидаемый результат:** проект запускается, тип `Task` импортируется без ошибок TS.

### Задание 2. Компоненты `TaskItem` и `TaskList`: props и emits (~40 минут)

1. Создайте `src/components/TaskItem.vue`: карточка задачи с чекбоксом и кнопкой удаления; props — `task: Task`; события — `toggle(id)` и `remove(id)`. Используйте типизированные `defineProps` и `defineEmits` из раздела 9.4–9.5.

2. Создайте `src/components/TaskList.vue`: принимает `tasks: Task[]`, рендерит `TaskItem` через `v-for` с `:key="task.id"`, пробрасывает события наверх.

3. Подключите `TaskList` в `App.vue` и реализуйте обработчики:

```ts
function toggleTask(id: number): void {
  const task = tasks.value.find((t) => t.id === id)
  if (task) task.status = task.status === 'done' ? 'todo' : 'done'
}

function removeTask(id: number): void {
  tasks.value = tasks.value.filter((t) => t.id !== id)
}
```

**Ожидаемый результат:** клик по чекбоксу переключает статус и перечёркивание, кнопка «✕» удаляет карточку. Обратите внимание: мы мутировали поле задачи внутри массива из `ref` — и интерфейс обновился, потому что `ref` для объектов создаёт глубокую реактивность.

### Задание 3. Форма задачи и `v-model` (~30 минут)

1. Создайте `src/components/TaskForm.vue` с двумя `defineModel`: `title` (обязательная) и `description` (по умолчанию пустая), как в разделе 9.6. Кнопка отправки эмитит событие `create`.

2. В `App.vue` заведите `draft = reactive({ title: '', description: '' })`, свяжите форму через `v-model:title` и `v-model:description`, по событию `create` добавляйте задачу в `tasks.value` и очищайте черновик.

3. Добавьте поиск: поле ввода, связанное `v-model` с `ref('')`, и `computed`, фильтрующий задачи по вхождению строки в название. Передайте в `TaskList` уже отфильтрованный массив.

**Ожидаемый результат:** задачи добавляются через форму, список мгновенно фильтруется при вводе — вы своими руками собрали двустороннее связывание в обе стороны.

### Задание 4. Жизненный цикл: автофокус и очистка (~20 минут)

1. В `TaskForm.vue` получите шаблонный `ref` на поле названия и сфокусируйте его в `onMounted`.

2. В `App.vue` подпишитесь в `onMounted` на `keydown` (например, по клавише `/` фокусировать поиск) и **обязательно** отпишитесь в `onUnmounted`.

3. Временно закомментируйте `onUnmounted` и убедитесь через Vue DevTools, что слушатель «переживает» компонент (это и есть будущая утечка памяти), затем верните очистку.

**Ожидаемый результат:** при загрузке страницы курсор в поле названия; клавиша `/` фокусирует поиск; слушатели корректно снимаются.
