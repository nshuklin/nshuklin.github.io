# Тема 09. Vue Composition API и переиспользуемые composables

## Практическая часть

Контекст: проект из темы 9 уже умеет показывать, добавлять и фильтровать задачи. Сегодня добавим ему адаптивность, «умный» поиск и заодно понаблюдаем за курсором (исключительно в научных целях).

### Задание 1. `useDebounce` и «умный» поиск (~35 минут)

1. Создайте `src/composables/useDebounce.ts`:

```ts
import { onScopeDispose, ref, watch, type Ref } from 'vue'

export function useDebounce<T>(source: Ref<T>, delayMs = 300): Ref<T> {
  const debounced = ref(source.value) as Ref<T>
  let timer: ReturnType<typeof setTimeout> | undefined

  watch(source, (value) => {
    clearTimeout(timer)
    timer = setTimeout(() => {
      debounced.value = value
    }, delayMs)
  })

  onScopeDispose(() => clearTimeout(timer))
  return debounced
}
```

2. В `App.vue` заведите `const search = ref('')`, получите `debouncedSearch = useDebounce(search, 400)` и фильтруйте задачи по `debouncedSearch`.

3. Рядом с полем поиска выводите индикатор: если `search !== debouncedSearch`, показывайте «Ищем…».

**Ожидаемый результат:** при быстром вводе список пересчитывается не на каждое нажатие клавиши, а через 400 мс после паузы; индикатор появляется и исчезает.

### Задание 2. `useBreakpoints` и адаптивная доска (~35 минут)

1. Создайте `src/composables/useBreakpoints.ts`:

```ts
import { computed, onScopeDispose, ref } from 'vue'

export type Breakpoint = 'mobile' | 'tablet' | 'desktop'

export function useBreakpoints() {
  const width = ref(window.innerWidth)

  const breakpoint = computed<Breakpoint>(() =>
    width.value < 640 ? 'mobile' : width.value < 1024 ? 'tablet' : 'desktop',
  )

  const onResize = (): void => {
    width.value = window.innerWidth
  }

  window.addEventListener('resize', onResize)
  onScopeDispose(() => window.removeEventListener('resize', onResize))

  return {
    width,
    breakpoint,
    isMobile: computed(() => breakpoint.value === 'mobile'),
  }
}
```

2. В проекте используйте `isMobile`: на мобильных устройствах колонки статусов («К выполнению», «В работе», «Готово») складываются в вертикальный список, на десктопе — стоят рядом.

3. Проверьте в DevTools: режим адаптивного дизайна, изменение ширины — колонки перестраиваются без перезагрузки.

**Ожидаемый результат:** интерфейс приложения реагирует на ширину окна одним движением `computed`.
